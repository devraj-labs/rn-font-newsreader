# Creating a Font Package

## Prerequisites

- Node.js + npm
- Python 3.10+ (for the generate script — `fonttools` is installed automatically into a venv)
- `gh` CLI if you want to create the GitHub repo from the terminal

---

## Steps

### 1. Create a repo from the template

**Option A — GitHub template (recommended)**

Click **Use this template** on GitHub to create a new repo under your account, then clone it:

```bash
git clone https://github.com/<your-org>/rn-font-<fontname>.git
cd rn-font-<fontname>
```

**Option B — Clone directly**

```bash
git clone https://github.com/devraj-labs/rn-font-template.git rn-font-<fontname>
cd rn-font-<fontname>
git remote set-url origin https://github.com/<your-org>/rn-font-<fontname>.git
```

### 2. Init

```bash
npm run init
```

Prompts for one thing:

```
Font name (e.g. inter, jetbrains-mono): inter
```

Automatically derives the package name and repo URL from the scope already in `package.json`:
- `@devraj-labs/rn-font-inter`
- `https://github.com/devraj-labs/rn-font-inter`

Also renames `README.md` → `README-TEMPLATE.md`, archiving the template's contributor docs so the next step can write a consumer-facing README in its place.

To skip the prompt: `node scripts/init.js --name inter`

### 3. Add your font files

Drop static `.ttf` files into `assets/fonts/`. One file per weight — no variable fonts.

```
assets/fonts/
├── Inter-Regular.ttf
├── Inter-Medium.ttf
├── Inter-SemiBold.ttf
└── Inter-Bold.ttf
```

Fonts with multiple optical sizes (e.g. Newsreader 14pt / 24pt / 36pt) are supported — just drop all files in and `generate` handles the grouping automatically.

### 4. Generate

```bash
npm run generate
```

Reads every `.ttf`, groups by font family, infers CSS weight tokens from subfamily names, writes `src/index.ts`, and generates a consumer-facing `README.md` with install instructions, a usage example, and a full font map table.

**Single family** (e.g. Inter):
```ts
export const interFonts: TFontPackage = {
  inter: {
    '400': 'Inter-Regular',
    '700': 'Inter-Bold',
  },
};
```

**Multiple optical sizes** (e.g. Newsreader):
```ts
export const newsreaderFonts: TFontPackage = {
  newsreader14pt: { '400': 'Newsreader14pt-Regular', '700': 'Newsreader14pt-Bold' },
  newsreader24pt: { '400': 'Newsreader24pt-Regular', '700': 'Newsreader24pt-Bold' },
};
```

Dry run without writing: `npm run generate -- --dry-run`

See [README generation](readme-generation.md) for details on what the generated README contains.

### 5. Publish

```bash
npm login   # if not already logged in
npm run release
```

---

## Why static fonts?

iOS resolves `fontFamily` by PostScript name. Android resolves by filename (without extension). Static fonts following the `Family-Weight` naming convention satisfy both with no platform branching. Variable fonts require `Platform.select` to work correctly across both platforms — not worth the complexity.

## Repository structure

```
rn-font-template/
├── assets/fonts/          # your .ttf files go here
├── scripts/
│   ├── init.js            # npm run init
│   └── generate-font-package/
│       ├── run.sh
│       ├── generate-font-package.py
│       └── requirements.txt
├── src/index.ts           # auto-generated by npm run generate
├── react-native.config.js # asset linking for consumers
├── package.json
└── tsconfig.json
```
